The everyday workflow

Connect. Watch. Respond.

  1. Connect your channel.

    Install the Windows app and approve the requested permissions on KICK’s own authorization page.

  2. Choose the controls you want.

    Run Pre-Stream Check. Enable the shields that fit your channel and choose the recommended review-first Network Shield preset.

  3. Keep streaming.

    StreamShield receives channel events while the desktop app stays open. Use the compact window to review alerts and act on a specific message or account.

  4. Review and follow up.

    Check verification results, handle possible repeat abuse, correct mistakes with the appropriate recovery control, and review the stream report afterward.

Walk through the full process
Network Shield

Make repeat abuse easier to review.

Bring a viewer’s consented verification history into the moderation decision—without making your team manage raw IP addresses.

A quieter check for viewers

The viewer receives a neutral “Please verify to chat” message and opens a StreamShield page. After reviewing the privacy notice, they continue with the KICK account selected by the request.

A clean result can restore the temporary restriction StreamShield owns. A result that needs review stays with the moderation team.

A clearer decision for moderators

With Network Shield enabled, banning a previously verified account lets the signed ban event mark its retained network history. A later verification from a blocked network becomes a possible repeat-abuse signal.

Review-first is recommended: shared or changing connections can link unrelated viewers. Account bans, network blocks, and their recovery controls stay separate.

Network checks apply to viewers who complete StreamShield verification. This is channel chat moderation, not a KICK-wide network block.

Start here

Set up before your next stream.

  1. Download and extract.

    Save the Windows ZIP, right-click it, and choose Extract All.

  2. Run the installer.

    Open Install StreamShield.cmd, then launch StreamShield from the desktop shortcut.

  3. Sign in and check readiness.

    Select Connect KICK, choose your protection settings, and run Pre-Stream Check. Keep the app open while your channel is being moderated.
