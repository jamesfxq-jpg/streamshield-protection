The everyday workflow

Connect. Watch. Respond.

  1. Connect your channel.

    Install the Windows app and approve the requested permissions on KICK’s own authorization page.

  2. Choose the controls you want.

    Run Pre-Stream Check. Enable the shields that fit your channel and choose the recommended review-first Network Shield preset.

  3. Keep streaming.

    StreamShield receives channel events while the desktop app stays open. Use the compact window to review alerts and act on a specific message or account.

  4. Review and follow up.

    Check verification results, handle possible repeat abuse, correct mistakes with the appropriate recovery control, and review the stream report afterward.

Walk through the full process
Network Shield · IP Ban and Unban

Block repeat abuse. Unblock a network when you need to.

StreamShield makes IP-based moderation easier to manage: your team works with privacy-protected network history instead of typing or exposing full IP addresses.

REVIEW FIRST

IP Ban — Block a verified network

When a viewer completes StreamShield verification, the system can recognize their network using a masked identifier. If a moderator chooses Ban & Shield, StreamShield bans that KICK account and checks any retained verified network history. With Network Shield enabled, the confirmed ban event can mark that network history as blocked.

If another account later verifies from a blocked network, moderators can see a possible repeat-abuse match and decide what to do next. The recommended setup asks for review rather than automatically banning every match.

UN-IP Ban — Remove Network Block

Need to reverse a network block? Open Network History in the StreamShield dashboard, select the blocked masked network entry, and choose Remove Network Block. This lifts that network block without disturbing other moderation records.

Unbanning the network is not the same as unbanning the account. If the KICK account is still banned, use the separate Unban action to restore that account's chat access.

What if someone never verified? You can still ban their KICK account, but StreamShield cannot associate an unverified account with a network block. The dashboard will show that its verified network history is unavailable.

Good to know: Networks can be shared by families, workplaces, or other viewers. A network match is a reason to review the account, not proof that it is the same person. See the full moderation workflow.
