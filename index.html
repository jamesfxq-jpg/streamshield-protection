INSTALLATION

Download and install on Windows

Download the Windows Beta.
Click the green Download Windows Beta button above. Your browser downloads a ZIP file.
Extract the ZIP.
In File Explorer, right-click the downloaded ZIP and choose Extract All. Do not run StreamShield from inside the compressed ZIP.
Run Install StreamShield.
Open the extracted folder and double-click Install StreamShield.cmd. The beta installer sets up its own verified Node.js runtime if needed.
Use the desktop shortcut.
After installation, launch StreamShield from the desktop shortcut. Keep StreamShield running while you stream.
Windows beta notice: this beta is not yet signed with a commercial Windows publisher certificate. Windows may show an Unknown Publisher/reputation warning. If Windows blocks the file outright, do not disable Smart App Control or other system-wide security protections; stop and contact the StreamShield beta operator.
FIRST RUN

Connect your Kick account

Click Connect Kick.
Your normal browser opens Kick's official authorization page.
Review the permissions.
StreamShield requests user/channel read access, event subscriptions, and supported moderation permissions. It does not request your stream key, advertising controls, payout settings or chat-posting permission.
Approve StreamShield.
Kick redirects back to the local StreamShield app. Your OAuth tokens are encrypted on your own PC.
Confirm the dashboard is healthy.
You should see your Kick username, channel status, threat score and Event Board. Keep Assist mode on for normal beta use.
HOW TO USE STREAMSHIELD

What to do while streaming

  • Leave Assist mode on. StreamShield monitors viewer/follow/chat anomalies and explains suspicious activity without aggressively moderating normal chat.
  • Watch the Event Board. This private feed shows health changes, detections and defensive actions without posting attack details into public chat.
  • Use Shield Mode for an active incident. The green Activate Shield button switches StreamShield to the strongest supported defensive posture you have authorized. It does not mass-ban viewers.
  • Keep automatic timeouts off at first. Targeted automatic timeouts are a separate opt-in for very high-confidence repeated spam from the same untrusted account. The broadcaster and trusted chatters are excluded.
  • Add regulars as Trusted Chatters. Use the dashboard's trusted-chatter controls for people you never want automatically timed out.
  • Review suspicious chat before taking destructive action. Delete-message and timeout controls use Kick's supported moderation APIs.
  • Generate an incident report after a serious event. Reports summarize timing, anomaly reasons and actions taken as supporting evidence. They do not claim to prove who caused the traffic.
  • Optional OBS overlay. Copy the private OBS Browser Source URL from the dashboard into an OBS Browser Source if you want a small protection-status overlay. Do not share that keyed URL publicly.
STATUS GUIDE

What the dashboard statuses mean

READY / PROTECTED Kick connection and required monitoring are healthy.

ELEVATED / SUSPICIOUS StreamShield sees unusual behavior and is increasing monitoring or recommending action.

MONITORING DEGRADED A Kick API, subscription, internet or backend path is unavailable. StreamShield will show the reason instead of pretending protection is complete.

A threat score is an anomaly indicator, not proof that a person is botting. Normal viewer spikes, raids, promotions and viral traffic can be legitimate.

TROUBLESHOOTING

If something does not look right

  • Connect Kick button keeps returning: close StreamShield, reopen it, and authorize Kick again.
  • Monitoring degraded: read the Event Board health message first. It identifies whether the issue is Kick API access, event subscriptions, internet connectivity or the StreamShield backend.
  • No viewer count: viewer polling may remain zero while the channel is offline. Live viewer validation requires an actual Kick stream.
  • No recent chat: chat events appear only when Kick sends them for your connected channel. Do not generate fake engagement just to test StreamShield.
  • Need a clean reset: use Disconnect Kick, or Delete My StreamShield Data if you also want the local baseline/incidents and cloud webhook buffer removed.
  • Windows blocks installation: do not turn off Smart App Control globally. Use the closed-beta support path until commercial code signing is complete.
ACCOUNT SAFETY

No metric manipulation

StreamShield never generates viewers, follows, chat, subscriptions, raids or other engagement. It does not change KPP, ads, payout or stream-key settings.

PRIVACY

Minimize what leaves the streamer's PC.

Streamer OAuth tokens are encrypted locally. The cloud OAuth broker handles authorization codes and refresh tokens only long enough to exchange or refresh them and does not persist them. Public chat text buffered for real-time detection expires after 15 minutes; webhook event rows expire after 24 hours. StreamShield does not collect viewer IP addresses, passwords, private messages or stream keys.
