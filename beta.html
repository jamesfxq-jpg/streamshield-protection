A useful first test.

  1. Install, connect, and check.

    Use the current build, connect the correct KICK account, and run Pre-Stream Check. Note any pending or failed items.

  2. Confirm a normal channel event.

    With a consenting test account, send an ordinary chat message and confirm it appears in recent activity.

  3. Try the verification flow.

    Use Verify / Resend on that test account. Check the delivered link, account check, result, and clean chat restoration.

  4. Review moderator tools and recovery.

    Check Compact Control, one authorized moderator invite, a harmless action, and its recorded outcome. Use only consenting accounts for controlled restrictions or bans.

  5. Send the details.

    Tell us your build number, the steps you took, what you expected, and what happened. Include a screenshot only after removing private information.

Keep the whole team on the current release.

Close StreamShield before updating. Extract the new ZIP, run the installer, reconnect when asked, and rerun Pre-Stream Check. Web moderators reload their dashboard and renew their sign-in if prompted.

Test with care.

Start with review-first settings and keep KICK’s normal controls available. Beta behavior can change or produce incorrect results. Use consenting accounts for controlled moderation tests, and keep passwords, tokens, stream keys, private messages, and full viewer IP addresses out of reports.
