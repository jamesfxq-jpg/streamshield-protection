Checking this verification link…

By selecting Continue with KICK and completing authorization, you consent to the following collection for this channel’s moderation:

  • Your KICK account identity will be linked to this verification.
  • This connection’s exact public IP address will be stored encrypted at rest. Authorized channel moderation controls can view it and use an exact match to a blocked connection as a moderation signal.
  • A random first-party browser cookie, lasting up to 90 days, will support targeted verification. StreamShield stores a keyed one-way hash of its token on the server. This is a resettable browser token, not a hardware ID or an invasive fingerprint.

Shared connections matter. Public IPs can be shared or reassigned. If the streamer has enabled exact-network automatic bans, a verified account that matches a blocked IP can be banned. Contact the channel’s moderators if a match appears incorrect.

Use the KICK account for which the moderator requested verification. A browser-token match is a moderator review signal by default. Clearing cookies or switching browsers can reset the token; it does not remove an existing account ban.

KICK does not give StreamShield viewer IP addresses. This verification uses the connection you make to StreamShield. No hardware serial numbers, canvas fingerprints, or other invasive device fingerprints are collected.

You can close this page without starting verification. If a moderator has restricted chat pending verification, contact them to discuss access.
