Update in four steps.

  1. Close the running app.

    Stop StreamShield before replacing its files. Keep a private backup of your existing application data.

  2. Download and extract the ZIP.

    Choose Extract All, then open the extracted folder.

  3. Run Install StreamShield.cmd.

    The installer replaces program files while retaining the existing data directory.

  4. Reconnect and check readiness.

    Open the desktop shortcut, select Connect KICK, and run Pre-Stream Check. Choose the review-first Network Shield preset for the recommended setup.

Why you may be asked to sign in again.

A required-update rollout can expire StreamShield cloud installation access and web moderator sessions. Reconnecting through the current app establishes a fresh session.

This applies to StreamShield access. Your KICK website sign-in, account bans, stored network blocks, and channel settings are separate.

For web moderators.

Reload the dashboard after the streamer has updated and reconnected. Open a valid private invite to sign in again. Ask the streamer for a fresh invite when the previous one has expired or been used.

The streamer’s app must be running for your queued moderation commands to complete.

Check that your update is complete.

Confirm the app reports 0.6.0-beta.14, finish the KICK reconnect, and check the cloud relay and signed-event status. A downloaded ZIP alone is not an active, updated installation.

Offline installations are checked when they next connect. Older builds may show an update notice or cloud connection error until replaced.
