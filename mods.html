STREAMER + MODERATOR GUIDE

Simple tools for the people protecting the chat.

The streamer chooses exactly which KICK accounts get StreamShield access. Selected moderators connect with their own KICK account and receive a separate remote Mod Dashboard with a Compact Pop-Out.

Streamer control

Select only the mods you want.

Have the moderator send one message in KICK chat, then click Invite Mod beside that exact account in StreamShield. The invite is bound to that KICK user ID and expires if unused.

The streamer can see approved and pending moderators under Moderator Access and revoke access at any time.

Remote moderator access

The mod gets their own dashboard.

The selected moderator opens the private invite, clicks Connect with KICK, and signs in with their own KICK account. StreamShield then opens a restricted remote Mod Dashboard with a Compact Pop-Out.

No streamer password, OAuth token, stream key, Windows login, Full Protection settings, data-delete controls, or full viewer IP addresses are exposed to the mod.

Targeted verification

Verify a chatter: Select → Send → Verified.

1
Find the chatter

Open Recent KICK Chat in the dashboard or Compact Control.

2
Click Verify

Choose Require Verification in the full dashboard or Verify in Compact Control beside that person.

3
Message is copied

StreamShield temporarily restricts that account, creates a one-time link, and copies a ready-to-paste message containing @username + instructions + the link.

4
Paste it to the viewer

Paste the copied message into KICK chat while mentioning that viewer, or send it through a private contact method already used by the channel.

5
Review the result

The viewer selects Continue with KICK. StreamShield checks that the authorized KICK account is the exact account the moderator selected.

Example copied message
@username — StreamShield verification is required. Open this one-time link and select Continue with KICK: [verification link]
Compact Control

The easiest StreamShield screen for live moderation.

Click Compact Control on the main StreamShield dashboard. Keep the small window beside KICK or OBS during the stream.

Recent chat

See the latest chatters and use quick Case, Verify, 10-minute timeout, Ban, and Unban controls.

Verification queue

See which selected viewers are waiting, verified, blocked, or need review. Restore chat manually when appropriate.

IP & ban controls

Review blocked verified networks by masked network ID and use UN-IP BAN when a network block needs to be reversed. Full viewer IP addresses are never shown to moderators.

Recommended moderator routine: keep KICK chat open normally, keep Compact Control beside it, use Verify only for accounts you actually want checked, and review network matches before escalating moderation.

Remote Mod Dashboard

Built for selected human moderators.

Remote mods can review recent KICK chat, Delete messages, Require Verification, Timeout 10m, Permanent Ban, Unban, open Case Files, watch the verification queue, and review masked blocked-network IDs. Their commands are executed by the streamer’s authorized StreamShield desktop, which must remain running.

Compact Pop-Out: the moderator can open a smaller always-on-top-sized browser window for live moderation without keeping the full dashboard on screen.
