FOR STREAMERS AND SELECTED MODERATORS

Keep the next moderation action close at hand.

Recent chat, verification results, case history, and recovery controls—without switching between a pile of separate tools.

Streamer setup

Install the current Windows build, connect KICK, and run Pre-Stream Check. Enable Network Shield with the review-first preset. Open Compact Control beside your normal chat and streaming tools.

Use Invite Mod for a selected account. Share that private invite with its intended recipient, who signs in with their own KICK account.

Moderator setup

Open your private invite, choose Continue with KICK, and use the invited account. The restricted Mod Dashboard includes a Compact Pop-Out for a smaller workspace.

The streamer’s desktop must stay open and connected to execute remote commands. A queued action is still waiting; check for a completed result before relying on it.

The controls you will use most.

Verify / Resend

Request an account-bound verification check and let StreamShield deliver the link. Resend an active request without applying another timeout.

Delete / Timeout

Remove a selected message or temporarily restrict a specific account. Check the outcome in the action history.

Ban & Shield

Apply the account ban and check retained verified network history. A “still syncing” or “unavailable” network result is distinct from the completed account ban.

Case files

Review recent messages, prior actions, verification results, and masked network history before escalating a decision.

Recovery Center

Reverse supported recent actions in the streamer controls. Review any separate account ban and network block individually.

Remove Network Block

Use the streamer’s network controls to reverse the network block when needed. The KICK account’s unban is a separate decision.

Recommended routine.

Keep normal KICK chat visible. Use verification only for accounts you need checked. Review possible network or browser-token matches alongside behavior and history. Check the completed result after each action.

After a required update: the streamer installs the current build and reconnects. Web moderators reload the current page and sign in again through a valid invite; the streamer can issue a fresh invite when needed.
